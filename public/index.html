⚙️ Server Configuration & Email Provider Integration

Mode: Simulation / Standby

To enable real-time transactional inbox delivery, set either RESEND_API_KEY or your SMTP_* credentials in the .env file. Without credentials, the system safely records and formats all outgoing emails with certificates into the system audit log without throwing errors.

# .env Email Configuration Examples
# Option 1: Resend (Recommended)
RESEND_API_KEY=re_123456789abcdef

# Option 2: SMTP (Gmail / SendGrid / Custom)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASS=your_app_password
FROM_EMAIL=mgr.iei.chapter@drmgrdu.ac.in
FROM_NAME="MGR IEI Students Chapter"
